# 工厂测试 App 中文 UI 重构设计

## 目标

把当前粗糙的测试界面重构为适合工厂一线小白使用的现代化中文界面。用户不需要理解 BLE、RSSI、PID 等技术词，也能按页面步骤完成测试。

## 设计原则

- 全中文，避免英文按钮和技术状态裸露。
- 强步骤：先连接设备，再控制设备，最后解绑删除。
- 强提示：每一步告诉用户“现在要做什么”和“为什么按钮不能点”。
- 强视觉：用卡片、步骤编号、状态标签、设备图标和颜色按钮降低理解成本。
- 不改 BLE 协议和工厂功能主流程，只重构 UI/文案/状态组织。

## 页面结构

页面顶部显示标题和总状态：

- 标题：`工厂测试工具`
- 副标题：`按 1-2-3 步操作：先连接，再测试，最后解绑`
- 状态条：显示当前状态文案，如 `请先扫描设备`、`已连接 2 台设备，可以开始测试`

步骤 1：选择产品和扫描设备

- 标题：`第 1 步：选择产品，扫描附近设备`
- 显示产品类型、PID/SKU、目标数量、信号阈值。
- 信号阈值使用滑杆，不允许手填数字。
- 目标连接数量使用滑杆和加减按钮，不允许手填数字。
- 提示：`设备越近，信号越强。系统会自动勾选信号好的设备。`
- 按钮：`开始扫描`、`停止扫描`

扫描弹窗：点击开始扫描后显示大弹窗，实时展示：

- `符合条件` 数量。
- `信号较弱` 数量。
- `已选择 / 目标数量`。
- 阈值内设备分组，默认勾选。
- 阈值外设备分组，可手动勾选。
- 每台设备有图标、序号、信号强弱、中文状态。

步骤 2：确认设备并连接

- 标题：`第 2 步：确认勾选设备，点击连接`
- 显示已勾选数量、已连接数量。
- 设备卡片用图标和中文状态：`待连接`、`连接中`、`已连接`、`测试成功`、`失败`、`已解绑`。
- 按钮：`连接勾选设备`

步骤 3：测试灯光

- 标题：`第 3 步：测试灯光颜色`
- 只有连接设备后才强调可操作。
- 普通设灯：红、绿、蓝、白、黑。
- 最高亮度：先选红、绿、蓝、白、黑，再点 `测试最高亮度`。
- 设置 PID 独立成按钮：`写入产品型号`

步骤 4：完成后解绑

- 标题：`第 4 步：测试完成，一键解绑`
- 提示：`解绑后设备会从 App 删除，方便下一批测试。`
- 按钮：`一键解绑删除`

## 文案要求

所有面向工厂用户的文案必须中文。可以保留技术字段的小标签，但需要解释：

- `信号` 替代 `RSSI`，必要时显示 `信号 -45 dBm`。
- `产品类型` 和 `产品型号` 替代 `Product Type / PID`。
- `已连接` 替代 `Ready`。
- `上次结果`、`错误原因` 替代 `Last`、`Error`。

## 验收标准

- 首屏能看出操作顺序。
- 信号阈值和目标数量通过滑杆/拨盘调整，不要求用户输入数字。
- 扫描时有弹窗或新页面，实时显示阈值内、阈值外、已选择数量。
- 不连接设备时，测试按钮有明确禁用提示。
- 设备列表每台设备有图标、名称、信号、勾选框和中文状态。
- 普通设灯和最高亮度测试都有红绿蓝白黑颜色按钮。
- 所有主要按钮和提示都是中文。
